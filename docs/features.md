# 機能仕様

## AI サービス切り替え

画面左下のアイコンをクリックすることで AI サービスを順番に切り替えます。

| 状態 | アイコン | AI |
|------|---------|-----|
| 0 | claude-ai.png | Claude (Anthropic) |
| 1 | chatgpt-ai.png | ChatGPT (OpenAI) |
| 2 | gemini-ai.png | Gemini (Google) |

切り替えはローテーション形式 (0 → 1 → 2 → 0) で動作します。

## モデル切り替え

モデルアイコンをクリックすることで高性能モード / 経済モードを切り替えます。

| フラグ (`b`) | ChatGPT | Claude | Gemini |
|-------------|---------|--------|--------|
| `1` (高性能) | chatgpt-4o | claude-3-7-sonnet | gemini-2.0-flash |
| `0` (経済的) | gpt-4o-mini | claude-3-5-haiku | gemini-2.0-flash |

> デフォルトは高性能モード (`model = 1`)。

## メッセージ送信

テキストエリアにメッセージを入力して SEND ボタンで送信します。

### 応答待ち中の送信予約

通常の AI チャットを送信すると、入力欄はすぐにクリアされるため、応答を待っている間も次の下書きを入力できます。応答待ち中に入力した下書きテキストと貼り付け画像は、直前の応答が届いても保持されます。

通常の AI チャットのリクエスト中は SEND ボタンが「次に送信」に変わり、次の通常チャットを 1 件だけ予約できます。予約時にはテキスト・画像・AI サービス・モデルがスナップショットされ、予約された AI サービスとモデルが表示されます。予約中の入力欄は読み取り専用です。「予約を取り消して編集」をクリックすると自動送信を取り消し、予約済みの下書きを編集できる状態に戻します。

現在の応答が成功すると、予約したリクエストが予約順に自動送信されます。Tauri リクエストがエラーになった場合は予約を解放し、予約した下書きを保持します。自動再試行は行いません。

`/raw`、`/all`、`/image` コマンドは予約できず、アイドル状態のときだけ実行されます。AI の応答待ち中または送信予約中は、保存とリセットを利用できません。

送信に失敗した質問は、入力欄の下にある「送信に失敗した質問」から確認・コピーできます。
次の下書きを上書きせず、失敗した質問と画像を保持します。自動再送はしません。

### テキストコマンド

入力欄に以下のコマンドを入力することで特殊な処理を実行できます。

| コマンド | 動作 |
|---------|------|
| `/raw` | 会話履歴をマークダウン変換なしで表示 (`\n` → `<br>` のみ) |
| `/all` | 会話履歴をマークダウン HTML に変換して表示 |
| `/image <プロンプト>` | DALL-E 3 による画像生成。結果画像を表示 |

### 会話履歴の表示形式

`/all` および `/raw` で表示される形式:

```
user: <メッセージ内容>

assistant: <AIの回答>
--------------------

user: <次のメッセージ>
...
```

## 音声入力

マイクアイコンをクリックすることで音声認識を開始・停止します。

音声入力は任意の機能です。音声認識に非対応の環境やマイクが利用できない場合も、
テキスト入力・送信・会話履歴の表示は引き続き利用できます。この場合はマイクボタンだけが
無効になり、理由を画面に表示します。マイクの設定・権限を変更した場合はアプリを再起動してください。

- 言語: 日本語 (`ja`)
- 認識した音声はリアルタイムでテキストエリアに反映
- 以下の**音声コマンド**で自動送信が可能:

| 音声コマンド | 動作 |
|-------------|------|
| 「～エンター。」 | 「エンター」を除いたテキストを送信 |
| 「～送信。」 | 「送信」を除いたテキストを送信 |
| 「～教えて。」 | そのままのテキストを送信 |

## 回答の読み上げ (Gemini TTS)

画面左下のスピーカーボタン (🔊) をクリックすると、表示中の AI の回答を Google Gemini TTS で読み上げます。
読み上げ中にもう一度クリックすると停止します。

- 声: 入力欄上部のドロップダウンで「女性の声」「男性の声」を選択 (選択は次回起動時も保持)
- モデル: `gemini-3.8-flash-tts` (2026年9月リリースの Gemini 3.8 Flash TTS)
- 音声: Voice Library の東京アクセントの日本語音声

| 選択 | 音声 ID | Voice Library の説明 |
|------|---------|---------------------|
| 女性の声 | `ja-jp-techagent-7` | Tokyo Japanese, female, clear, medium-pitch, and friendly |
| 男性の声 | `ja-jp-advisor-8` | Tokyo Japanese, male, clear, medium-pitch, and friendly |

読み上げの動作:

- 回答末尾の `Model: ..., Total token: ..., Elaps: ...s` とコードブロックは読み上げません (コードは「コードは省略します」と読みます)
- 数式は TeX 表記のテキストとして読みます
- 長い回答は文単位で分割し、最初の約120文字をすぐ再生しながら、続き (約400文字ずつ) を先読みして生成します
- 新しい回答が表示された場合や音声入力を開始した場合は、読み上げを停止します
- 読み上げを開始すると、読み上げ音声をマイクが拾わないよう音声入力を停止します
- 読み上げには `GOOGLE_GEMINI_API_KEY` が必要です。失敗した場合は画面下部にエラーを表示します

モデルと声は環境変数で変更できます ([セットアップ](setup.md) を参照)。
棒読みちゃんによる自動読み上げ (`VOICEID`) とは独立した機能です。

## 画像入力

AI に画像を添付して質問できます。

### クリップボードから貼り付け

テキストエリアにフォーカスした状態で画像を貼り付け (`Ctrl+V`) すると:
- 自動的に最大 512×512px にリサイズ
- Base64 データ URL に変換
- プレビューとして表示

### ファイルのドラッグ＆ドロップ

テキストファイルをアプリ画面にドラッグ＆ドロップすると、ファイルパスと内容がテキストエリアに挿入されます。

挿入形式:
```
/path/to/file.rs
```rust
// ファイルの内容
\```
```

- ディレクトリや存在しないファイルはスキップ
- 複数ファイルを一度にドロップ可能

## システムプロンプト

ドロップダウンからシステムプロンプトを選択することで AI の振る舞いを変更できます。

### `[system]` プロンプト (Rust 側で管理)

バックエンドの `system_messages` に設定され、AI の役割を定義します。

| 選択肢 | 内容 |
|--------|------|
| 厳格で正確な | 法律・規則に従った正確かつ厳格な回答 |
| 肯定的な | ユーザーのモチベーション向上に注力 |
| 批判的な | 建設的な批判的視点を提供 |

### `[user]` プロンプト (フロントエンド側で管理)

テキストエリアに直接プロンプトを挿入します。

| 選択肢 | 内容 |
|--------|------|
| 自己分析 | 会話履歴から自己分析を行う |
| まとめ | 会話を要約・#タグ付きで出力 |
| 引き継ぎ | 後任への引き継ぎプロンプトを作成 |
| クライアントメール用応答 | 簡潔・結論ファーストのメール文面に変換 |
| クライアントメール用配慮 | 相手を慮った配慮メール文面に変換 |

## 会話履歴の保存 (メモ)

削除アイコン (delete.png) をクリックすると:

1. 現在の会話履歴をファイルに保存
2. 保存に成功した場合だけ、会話履歴とシステムプロンプトをリセット (`memo_and_reset`)

保存に失敗した場合はエラーを表示し、会話履歴と画面の回答・送信済み画像を保持します。
AI の応答待ち中や保存中はリセットできません。保存中はメッセージ送信もできません。
未送信の入力と添付画像はリセット後も保持します。

### 保存先

```
~/Documents/.appdata/Talk with RustGPT/
```

### ファイル名

| 条件 | ファイル名 |
|------|-----------|
| 会話内に `#タグ` がある | `memo-YYYY-MM-DD_HH-MM-SS-タグ名.txt` |
| タグなし | `memo-YYYY-MM-DD_HH-MM-SS.txt` |

同名のファイルが存在する場合は連番を付け、既存のメモを上書きしません。

### 自動保存

ウィンドウを閉じたときにも自動的にメモが保存されます (`on_window_event` で `Destroyed` イベントを監視)。

## レスポンス表示

AI からの回答は以下の形式で表示されます:

```
<マークダウン→HTML変換されたAI回答>

Model: <使用モデル名>, Total token: <合計トークン数>, Elaps: <経過秒数>s
```

- マークダウンは GFM (GitHub Flavored Markdown) に対応
- 数式 (math_flow / math_text) に対応
- テーブル・タスクリストに対応
- コードブロックは highlight.js でシンタックスハイライト

## 質問テキストの表示

最後に送信した質問は画面上部に表示されます。

- 25文字以上の場合は末尾に `...` で省略
- クリックするとクリップボードにコピーされる

## 画像生成 (DALL-E 3)

`/image <プロンプト>` コマンドで DALL-E 3 による画像生成を実行します。

- サイズ: 1024×1024px (固定)
- 生成後はプロンプトと画像 URL を表示
- 会話履歴には追加されません
